| Пункт | Значение |
| --- | --- |
| Основной файл рукописи | `latex/main.tex` |
| Текущий стиль сборки | Локальный LaTeX (`latexmk` / `pdflatex`) |
| Статус папки i18n | `i18n/` существует (языковые файлы могут добавляться со временем) |
| Статус файла лицензии | Пока отсутствует |

## 📌 Обзор

Сейчас этот репозиторий предоставляет:

- Один основной исходный файл рукописи: `latex/main.tex`.
- Типовую структуру статьи с аннотацией, методами, алгоритмом, результатами, обсуждением и заключением.
- Подключение LaTeX-пакетов для типичных исследовательских задач (математика, цитирование, глоссарий, перекрестные ссылки).
- Метаданные пайплайна в `.auto-readme-work/` для генерации многоязычных README.

Важное замечание по репозиторию:

- `AGENTS.md` описывает предполагаемые директории (`figures/`, `data/`, `artifacts/`, `code/`), но часть из них пока отсутствует в текущем дереве. Этот README сохраняет это намерение и явно помечает отсутствующие элементы.

## ✨ Возможности

- Математическая верстка через `amsmath`, `amssymb`, `bm`, `mathtools` и `siunitx`.
- Поддержка рисунков и таблиц через `graphicx`, `subcaption`, `booktabs` и `multirow`.
- Окружение алгоритмов через `algorithm` и `algpseudocode`.
- Поддержка цитирования через `natbib`.
- Поддержка глоссария и акронимов через `glossaries` (включен `\makeglossaries`).
- Перекрестные ссылки через `hyperref` и `cleveref`.
- Примерное содержимое уже добавлено: уравнение целевой функции с `\ell_1`-регуляризацией, уравнение SNR в dB, псевдокод градиентного спуска, таблица количественного сравнения и встроенные записи библиографии.

## ✅ Предварительные требования

Установите окружение TeX, включающее пакеты, используемые в `latex/main.tex`.

Минимальные практические требования:

- `latexmk`
- `pdflatex`
- `bibtex` (для работы с библиографией в стандартных сценариях)
- Инструменты глоссария, необходимые для workflows с `glossaries` (обычно `makeglossaries` из дистрибутива TeX)

Допущение:

- Имена и версии пакетов в этом репозитории не зафиксированы; используйте актуальный дистрибутив TeX Live или MiKTeX.

## 🚀 Использование

| Задача | Команда |
| --- | --- |
| Рекомендуемая сборка | `latexmk -pdf -interaction=nonstopmode -halt-on-error latex/main.tex` |
| Быстрая однопроходная сборка | `pdflatex latex/main.tex` |
| Очистка вспомогательных файлов | `latexmk -c latex/main.tex` |

Основная команда сборки (рекомендуется, из `AGENTS.md`):

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error latex/main.tex
```

Однопроходная компиляция (для быстрых итераций):

```bash
pdflatex latex/main.tex
```

Очистка вспомогательных LaTeX-файлов с сохранением PDF:

```bash
latexmk -c latex/main.tex
```

Ожидаемый рабочий процесс:

1. Редактируйте содержимое рукописи в `latex/main.tex`.
2. Соберите PDF.
3. Визуально проверьте верстку и ссылки в итоговом PDF.

## ⚙️ Конфигурация

Текущая конфигурация документа находится в `latex/main.tex`:

- Класс документа: `article` с `11pt,a4paper`.
- Макет страницы: `geometry` с `margin=1in`.
- Интервал: `\onehalfspacing`.
- Настройка цвета ссылок через пользовательский `linkblue` и параметры `hyperref`.
- Предопределенные акронимы и элементы глоссария для `CNN`, `SNR`, `HSI` и `event camera`.

Поведение игнорирования на уровне репозитория (`.gitignore`):

- Игнорирует большинство артефактов сборки LaTeX (`*.aux`, `*.log`, `*.pdf` и т.д.).
- По умолчанию игнорирует директории `artifacts/` и `data/`.

## 🛠 Примечания по разработке

Рекомендации из `AGENTS.md`:

- Держите исходники LaTeX под четкими заголовками `\section{}`.
- Последовательно используйте префиксы меток: `eq:` для уравнений, `fig:` для рисунков, `tab:` для таблиц и `alg:` для алгоритмов.
- Предпочитайте ссылки через `\cref{}`.
- Используйте имена ресурсов в нижнем регистре с дефисами (пример: `figures/snr-comparison.pdf`).
- Для вложенных блоков LaTeX используйте отступ в два пробела, где это улучшает читаемость.

Подход к валидации:

- Автоматизированного набора тестов нет.
- Основная валидация: успешная сборка LaTeX плюс визуальная проверка сгенерированного PDF.

## 🧰 Устранение неполадок

Типичные проблемы и проверки:

- Сборка падает из-за отсутствующего пакета: установите недостающие LaTeX-пакеты из вашего дистрибутива TeX.
- Не появляются элементы глоссария: убедитесь, что инструменты глоссария установлены, и повторно запустите `latexmk`, чтобы выполнились шаги глоссария.
- Не исчезают предупреждения по цитатам или ссылкам: пересоберите через `latexmk` (многопроходность обрабатывается автоматически).
- Итоговый PDF не отслеживается git: это ожидаемо, так как `*.pdf` сейчас игнорируется в `.gitignore`.
